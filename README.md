# 精密板金加工 学習ツール

製造業の **精密板金加工** を「設計 → 加工 → 検査」の流れで、初心者から実務レベルまで学べる学習用Webアプリです。
インストール不要・依存ライブラリなしの静的サイト(HTML / CSS / JavaScript)で動作します。

## 主な機能

| 機能 | 内容 |
|---|---|
| 📘 板金の基礎 | 精密板金とは、材料(SPCC/SECC/SUS/アルミ)、板厚・定尺・歩留まり、図面の読み方、安全と5S |
| 📐 設計 | 展開計算(K値・伸び値)、曲げ設計ルール(最小フランジ・穴距離・曲げ逃げ)、公差(JIS B 0405)、ねじ・締結、溶接設計、DFM、3D CAD |
| 🔧 加工 | レーザー切断、タレパン、バリ取り、プレスブレーキ曲げ、スプリングバック・曲げ割れ・特殊曲げ、溶接、表面処理、組立 |
| 🔍 検査・品質 | 測定器、曲げ品の測り方、検査の種類と成績書、幾何公差、不良対策、4M・Cpk・ポカヨケ |
| ▶ アニメーション | プレスブレーキ曲げ、スプリングバック、レーザー切断、タレパン、展開→折り曲げ、中立軸とK値、バーリング、ヘミング、圧延方向と曲げ割れ、穴と曲げ距離、スポット溶接、測定 など13種類(SVG + JavaScript) |
| 🏭 3D曲げ工程シミュレーター | プレスブレーキ(ラム・パンチ・ダイ・ベッド)の3Dモデル内で、板金部品を1曲げずつ工程順に成形。曲げごとの持ち替え(位置と姿勢の変更)を再現し、パンチ・ダイ・ラム・ベッドとの干渉を検出。視点は斜め/正面/横(断面)/上面/曲げ部アップのボタン切替とマウス操作の両方に対応。WebGLを直接使用し依存ライブラリなし |

## 使い方

### ローカルで開く
`index.html` をブラウザで開くだけで動作します(file:// でも可)。

ローカルサーバーを使う場合:
```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

### GitHub Pages で公開する
リポジトリの Settings → Pages → 「Deploy from a branch」で対象ブランチ・ルート(`/`)を選ぶだけで公開できます(ビルド不要)。

## コンテンツの追加・編集

- **レッスンを追加**: `js/data/*.js` の `lessons` 配列にオブジェクトを追加します。
  ```js
  { id:'my-lesson', title:'タイトル', level:2, minutes:10,
    body:`<p>本文HTML</p><div data-anim="press-brake"></div>`,
    tips:['ワンポイント'],
    quiz:[{q:'問題', opts:['A','B','C','D'], a:1, e:'解説'}] }
  ```
  `level` は 1=初級、2=中級、3=実務。
- **アニメーションを追加**: `js/animations.js` に `A['名前'] = function(container){ ...; return stopFn; }` を追加し、本文に `<div data-anim="名前"></div>` を書きます。
- **ノウハウ / アドバイス / 用語**: 各データファイルの配列に追加するだけです。

## 曲げシミュレーターの計算モデル

`js/simulator.js` は次の式・モデルで試算しています。いずれも一般的な代表値に基づく目安です。

| 項目 | 式・モデル |
|---|---|
| 曲げ伸び BA | `(π×θ/180) × (R + K×T)` |
| 外側セットバック OSSB | `(R + T) × tan(θ/2)` |
| 曲げ縮み BD | `2×OSSB − BA` |
| 展開長 | `Σ外寸 − ΣBD` |
| K値(自動) | R/T から内挿(R/T=0.25→0.32、1→0.42、2→0.45、4以上→0.50) |
| 標準V幅(自動) | 板厚から選定(板厚の6〜8倍が目安) |
| 曲げ内R(自動) | `V ÷ 材質係数`(軟鋼6.0、SUS5.3、アルミ5.6 など) |
| 必要荷重 | `P[kN] = 1.33 × σb × W × T² ÷ (V × 1000)` |
| 戻り角(スプリングバック) | 材質ごとの基準値 × (R/T)^0.6 × (V/8T)^0.25 × (θ/90) の経験式 |
| 断面形状 | 型線の交点列を中立面で丸め、板厚方向に±T/2オフセットして外形を生成 |

成形可否の判定は、最小曲げ内R、最小フランジ(0.7×V幅)、曲げR部の重なり、成形後の自己干渉、逆方向の短い段曲げ、機械能力超過、鋭角曲げを確認します。

### 金型干渉の判定方法

| 手順 | 内容 |
|---|---|
| 1. 機械座標への配置 | ダイ上面を y=0、V溝中心を x=0 とする座標系を取り、対象の曲げの外側二等分線が真下を向くよう部品を回転。外側型線の頂点を y = −(V/2)×tan(θ/2) に置く(板の外面がダイ両肩に接する位置) |
| 2. 金型断面の生成 | ダイはV角度・肩R・幅・高さから、パンチは先端角・肩幅・高さ・逃げ寸法から多角形を生成。パンチ先端は内側型線の頂点に配置 |
| 3. 干渉判定 | 部品外形を1.5mm間隔で点列化し、パンチ/ダイ多角形との内外判定を実施。境界からのめり込み量が 0.12mm を超えたら干渉とする |
| 4. 接触部の除外 | パンチ先端((R+T)×1.3+0.8 mm 以内)とダイ肩(肩R+0.6T+1.2 mm 以内)は正規の接触なので判定から除外 |
| 5. 曲げ角度の走査 | 0から目標角度まで9段階で判定し、最初に干渉する角度を報告 |
| 6. 曲げ順の探索 | 「成形済みの曲げの集合」をビットマスクとして状態を表し、(集合, 次に曲げる番号) の可否をメモ化。到達可能性を動的計画法で解き、全曲げを干渉なく成形できる順序を求める |

部品の中心線の頂点間距離は、外寸(型線間の寸法)から各曲げの型線オフセット `(T/2)/cos(θ/2)` を差し引いて求めるため、図示した外寸と成形後の寸法が一致します。

## 3D曲げ工程シミュレーターの仕組み

`js/sim3d.js` は依存ライブラリを使わず、WebGLを直接呼び出して描画しています。

| 要素 | 実装 |
|---|---|
| 部品モデル | 平面(面)を曲げ線でつないだ木構造。各ノードは親の辺上に置かれた局所座標系を持ち、曲げ角度ぶん回転させると立体になる。曲げ部は板厚中央の円筒帯として生成 |
| 機械モデル | ダイとパンチは2D断面をX方向に押し出して生成。ダイは分割ダイ、パンチは曲げ線の長さに合わせて分割・短く組む(箱曲げで立ち上がった壁を避ける定石) |
| 機械への配置 | 加工する曲げの軸をX方向に、外側二等分線を真下に向ける。曲げの前後は左右対称に起き上がる(実機と同じく板がダイ両肩を支点に回る) |
| 沈み込み量 | 解析式ではなく、部品頂点とダイ上面・V溝・ベッド上面の当たりから「載る高さ」を求める。原理的に食い込みが生じない |
| パンチ位置 | 曲げ部内側の最下点に先端を合わせ、加工中は板の動きに追従させる |
| 干渉判定 | パンチは断面多角形との内外判定(先端の正規接触は除外、パンチ長さの範囲のみ)。ダイは部品が正しく載らず浮き上がる量で判定。ラム(上部テーブル)とベッドは直方体との重なりで判定 |
| 視点 | 5種類のプリセットをボタンで切替。方位角・仰角・距離・注視点を毎フレーム補間して滑らかに移動。上面視ではラムとパンチを自動で非表示にして部品と金型が見えるようにする。ドラッグやホイール操作をするとプリセットの選択は解除される |
| 持ち替え | 前後の工程の姿勢をクォータニオン球面補間で結び、手前に引き出して戻す軌跡で移動。実機と同じくラムを部品の高さより上まで開いてから動かすため、移動中に金型と当たらない |

曲げ工程の順序はプリセットごとの並び順(または逆順)です。正確な展開長・曲げ荷重・干渉角度は2D断面のシミュレーターで数値として確認してください。
